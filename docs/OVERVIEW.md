## Quick Overview

pi-research is a pi CLI extension that runs multi-agent web research. It:

- Uses a stealth Firefox instance (camoufox) running in isolated worker processes to search and scrape the web without bot detection.
- Orchestrates one or more researcher agents that gather and synthesize information in parallel.
- Stores scraped content in a local LanceDB vector database for deduplication and cross-session retrieval.
- Renders live progress in pi's TUI.

**Depth levels:**

| Depth | Mode | Researchers | Rounds | Typical use |
|-------|------|-------------|--------|-------------|
| 0 | Quick | 1 | 1 | Fast single-question lookup |
| 1 | Normal | 2 | 2 | Standard research |
| 2 | Deep | 3 | 3 | Multi-angle analysis |
| 3 | Ultra | 5 | 5 | Exhaustive investigation |

**Research tools available to each researcher:**

- `search` — DuckDuckGo Lite via stealth browser
- `scrape` — batch URL scraping with PDF support
- `security_search` — NVD, CISA KEV, GitHub Advisories, OSV
- `stackexchange` — Stack Exchange network
- `grep` — local codebase search via ripgrep

For installation and usage see the [root README](../README.md).
